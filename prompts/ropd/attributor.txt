# 归因类型

每条 criterion 必须选择一种 attribution_type：

- `supporting_span`：回答中存在明确文本片段，能够实质支撑该 criterion。
- `explicit_error`：回答中存在明确文本片段，体现了与该 criterion 直接相关的事实错误、视觉误读、错误 policy mapping、逻辑矛盾或错误结论。
- `missing`：回答没有表达该 criterion 所要求的必要能力，也不存在可定位的明确错误片段。
- `global`：该 criterion 依赖跨多个步骤的整体逻辑或结论一致性，无法可靠归因到单个局部片段。

# Quote 规则

- 对 `supporting_span` 和 `explicit_error`，`quote` 必须是从对应 Student Answer 中逐字复制的一段短文本。
- 选择最小但仍足以解释归因的片段，不要复制整篇回答。
- 不得改写、总结、补全或修正原文。
- 对 `missing` 和 `global`，`quote` 必须为空字符串。
- 如果无法找到完全匹配的原文片段，不要虚构 quote，应使用 `missing` 或 `global`。
- 每条 criterion 只提供一个最主要的归因片段。本阶段仅用于 shadow 日志检查，不参与实际训练 reward。

# 输出格式

只返回 JSON object，不要输出 Markdown、解释或代码块：
{
  "schema_version": "ropd.shadow_attribution.v1",
  "answers": [
    {
      "answer_index": 1,
      "attributions": [
        {
          "criterion_id": "c1",
          "attribution_type": "supporting_span",
          "quote": "exact text copied from the student answer"
        },
        {
          "criterion_id": "c2",
          "attribution_type": "missing",
          "quote": ""
        }
      ]
    }
  ]
}

# 输出约束

- schema_version 必须严格等于 `ropd.shadow_attribution.v1`。
- answers 必须按输入顺序覆盖所有 Student Answer，answer_index 从 1 开始。
- 每个回答必须按 Rubrics 原始顺序覆盖每条 criterion，criterion_id 必须完全一致。
- quote 只能来自当前 answer，不能引用 Question、Rubrics、Known Final Label 或其他回答。
- 不要输出评分、points、judgement、建议答案或额外字段。
