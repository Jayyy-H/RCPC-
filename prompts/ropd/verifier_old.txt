# 核心评分规则
对每个回答，按 rubric 中 criterion 的顺序逐条判断：
- 如果该回答明确、具体、无矛盾地满足某条 criterion，则对应 judgement 为 true。
- 如果该回答没有明确满足某条 criterion，或者只是泛泛模板化提到相关概念，则对应 judgement 为 false。
- 如果一条 criterion 包含多个明确条件，只有当所有条件都满足时，才能判为 true。
- 每个回答都必须独立评分，不要因为其他回答更好或更差而改变当前回答的 judgement。
- 不要引入 rubric、题目、图片和已知最终标签之外的额外评分标准。
- 不要奖励更长、更自信、措辞更像标准答案或风格更好的回答，除非 criterion 明确要求这些属性。
- final_score 必须等于所有 judgement 为 true 的 criterion points 之和。

# 严格判分原则
- 不要从最终 `<answer>` 反推中间推理质量。只有 final label 正确，不代表 Preconditions、Violation Conditions、Exemptions、Evidence Grounding 或 Conclusion Consistency 正确。
- 不要把“提到了关键词”等同于“满足 criterion”。回答必须把关键词和本题具体证据、policy 条件建立正确关系。
- 如果 criterion 要求具体商品证据，回答必须引用或正确使用题目/图片中的具体信息，例如 title、description、seller-filled brand、suspected brand、image index、OCR/logo、similarity、reference pattern、类目等。泛泛说“images show similarity”“the product is branded”“no authorization”但没有本题可核查依据，通常判 false。
- 如果 criterion 要求 violation condition mapping，回答必须说明是哪一个具体 violation condition 被触发或未触发，并说明对应证据。只说“policy is violated / no violation”判 false。
- 如果 criterion 要求 exemption/boundary handling，回答必须明确说明 exemption 适用或不适用的理由。只写“No exemption applies”但没有结合 seller authorization、compatibility/adaptability、accessory、reference-only mention、category exclusion 等题目条件，通常判 false。
- 如果回答声称了 Question 或图片中不支持、相互矛盾或明显幻觉的关键事实，则与该事实相关的 evidence、precondition、violation、policy application criterion 必须判 false。
- 如果回答把 policy 适用对象搞错，例如把 Knockoff 当 Counterfeit/MBA、把 compatibility wording 当 design mimicry、把 reference image 当商品自身、把无品牌商品当 T1 genuine product，则相关 policy criterion 必须判 false。
- 如果回答的 `<answer>` 与 Known Final Label 不一致，任何关于最终结论正确性的 criterion 判 false；其他局部推理或格式 criterion 仍可独立判断。
- 如果回答没有严格输出单个非空 `<think>...</think>` 和单个 `<answer>Yes/No</answer>`，格式类 criterion 判 false。
- 如果多个回答最终 Yes/No 一样，也必须逐条检查它们的 `<think>` 内容、证据使用和 policy 映射；不要给相同 final answer 的回答自动赋相同分数。
- 对 JSON judgement 必须输出真正的 boolean 值 true/false，不要输出字符串 "true"/"false"。

# IPR/PBR 评分注意事项
- 评分时重点看回答是否按题目要求处理了 Preconditions、Violation Conditions、Exemptions 和 Conclusion。
- 对 Preconditions：只有明确检查当前 policy 的所有关键先决条件，并用本题证据说明满足或不满足，才判 true。
- 对 Evidence Grounding：只有正确使用本题具体证据，且没有把不存在或不确定的证据当成事实，才判 true。
- 对 Violation Conditions：只有把具体证据映射到 rubric 指定的 violation condition，才判 true。
- 对 Exemptions：只有明确检查题目中的 exemption/boundary 条件，并给出基于题目的理由，才判 true。
- 对 Conclusion Consistency：只有 conclusion 能由回答中明确的 precondition、violation、exemption 判断推出，且与 `<answer>` 一致，才判 true。

# 输出格式
只返回 JSON object，不要输出 Markdown、解释或代码块：
{
  "schema_version": "ropd.batch_verifier.v2",
  "answers": [
    {
      "answer_index": 1,
      "judgement": [true, false, true],
      "final_score": 7
    }
  ]
}

# 输出约束
- schema_version 必须严格等于 ropd.batch_verifier.v2。
- answers 数组必须包含每个输入回答各一项。
- answer_index 必须从 1 开始，并按输入顺序覆盖所有回答。
- 每个 judgement 的长度必须等于 rubric criterion 数量。
- final_score 必须等于该回答所有 true judgement 对应 points 的总和。
